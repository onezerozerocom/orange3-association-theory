# 연관 분석 모델 · 시뮬레이션 + 직접 풀기

연관 분석의 기본 개념(동시 구매표, 지지도·신뢰도·향상도, 향상도의 의미, 좋은 연관 규칙 찾기)을 **시뮬레이션으로 살펴보고, 각 단계의 빈칸을 직접 채우는** 웹앱입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없고, 웹에 올릴 때는 폴더의 파일을 모두 함께 올리면 됩니다(GitHub Pages 등).

## 구성

| 단계 | 시뮬레이션 | 채우는 칸 |
| --- | --- | --- |
| 먼저 알아보기 | 생각 열기, 활용 예, ‘음료 매출을 증가시켜라!’, 연관 규칙 찾는 순서 | – |
| 1. 동시 구매표 | 편의점 주문 6건, 굵은 숫자 칸을 누르면 해당 주문 강조 | 개념 빈칸, 동시 구매표 15칸, 가장 많이 함께 팔린 두 품목 |
| 2. 지지도 | 상품 A, B 선택 → 주문 카드 · 벤 다이어그램(전체 중 겹친 부분) · 지지도 계산 | ‘삼각김밥 → 사이다’ 지지도, A·B를 바꿀 때 O/X |
| 3. 신뢰도 | A가 없는 주문은 흐리게, 벤 다이어그램(A 중 겹친 부분) · 신뢰도 계산 | 신뢰도, 신뢰도의 뜻, A·B를 바꿀 때 O/X |
| 4. 향상도 | 신뢰도와 P(B)를 막대로 비교 · 향상도 계산 | P(사이다), 향상도, A·B를 바꿀 때 O/X, 두 막대 길이로 향상도 > 1 · = 1 · < 1 판단하기, 향상도의 의미 |
| 5. 연관 규칙 찾기 | 모든 규칙의 지지도·신뢰도·향상도 표와 산점도, 최소 지지도·신뢰도 조절 | 편의점 주문 40건에서 좋은 규칙 찾기, 지지도가 낮은 규칙을 거르는 까닭, 활용 방법 |
| 6. 종합 연습 | – | 객관식 5문항 + 저장 |

- 빈칸 근처에는 정답이 바로 보이는 내용을 두지 않았습니다. 바로 채점하는 연습문제와 도전 과제는 뺐습니다. 2~4단계에서 직접 계산하는 ‘삼각김밥 → 사이다’는 시뮬레이션에서 값을 가립니다. 향상도 값의 의미 문구는 빈칸으로 바꿨고, 연관 규칙 찾기에서는 ‘좋은 규칙 n개’ 숫자를 뺐습니다.
- 연관 규칙 찾기 데이터: 편의점 주문 6건 / 편의점 주문 40건(규칙을 심어 둔 **가상 데이터**: 컵라면↔삼각김밥, 빵↔우유 등).

## 저장

- 오른쪽 위 **저장하기**(또는 Ctrl + S)를 누르면 답이 **이 브라우저(localStorage)** 에 저장됩니다. 서버로는 아무것도 보내지 않습니다.
- 같은 컴퓨터·같은 브라우저로 다시 열면 저장한 답이 그대로 나옵니다. 저장하지 않고 탭을 닫으려 하면 한 번 묻습니다. 마지막 단계의 **저장한 답 지우기**로 지울 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `lib.js` · `app.js` · `style.css` | 이론 시뮬레이션 (데이터, 그래프, 단계) |
| `core.js` | 화면 엔진: 단계 이동, 슬롯 갱신, 끌기, 진행률 |
| `ws.js` | 빈칸, 단계별 배치, 정답이 보이는 부분 숨김, 저장하기 |
| `ws.css` | 빈칸 · 저장하기 버튼 · 배치 모양 |

`lib.js` · `core.js` · `style.css`는 회귀 분석(4번) · 군집 분석(7번) 이론 앱과 같은 파일입니다.
