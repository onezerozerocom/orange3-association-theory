# 연관 분석 모델 · 시뮬레이션 + 직접 풀기

편의점 거래 기록으로 **지지도 · 향상도 · 신뢰도**를 직접 계산하여, 어떤 행사를 할지 정해 보는 웹앱입니다. 단계마다 빈칸과 질문에 직접 답을 씁니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없고, 웹에 올릴 때는 폴더의 파일을 모두 함께 올리면 됩니다(GitHub Pages 등).

## 데이터

[표1] 편의점 거래 기록: 거래 5건 · 항목 4개 (컵라면, 삼각김밥, 핫바, 탄산음료), 거래마다 손님(나이 · 성별)을 함께 보여 줍니다.

[표1]의 숫자는 거의 모두 문제의 답이므로, 값을 계산해 보여 주는 시뮬레이션은 두지 않습니다. 항목을 고르면 그 항목을 모두 포함한 거래를 강조하는 도구만 있고, 개수는 보여 주지 않습니다.

## 구성

| 단계 | 보여 주는 것 | 채우는 칸 |
| --- | --- | --- |
| 먼저 알아보기 | 단계별 순서 | – |
| 개념 | – | 생각 열기, 개념 빈칸 7개 (맥주와 기저귀 이야기, 오늘의 질문 제시) |
| 1단계 항목집합 | [표1] 항목 고르기 · 거래 강조 | 전체 거래 수, 1~4-항목집합과 개수, 전체 항목집합 수 |
| 2단계 지지도 | 지지도 정의, [표1] 항목 고르기 | 항목집합 14개의 포함 거래 수 · 빈발 O/X (계산식 · 지지도는 포함 거래 수로 자동 작성), 최소 건수 (O를 고르면 그 줄이 하늘색) |
| 3단계 향상도 | 향상도 정의 | 빈발 2-항목집합 2개의 향상도 계산식(분수 모양에 지지도 세 개를 씀, 향상도는 자동 계산), 독립과 비교(< 1 / = 1 / > 1), 향상도가 더 낮은 까닭 |
| 4단계 신뢰도 | 신뢰도 정의 | 규칙 3개의 신뢰도 계산식([ ] ÷ [ ], 신뢰도는 자동 계산) · 백분율, 방향을 바꾸면 신뢰도가 달라질 수 있는 까닭 |
| 5단계 종합 | – | 세 지표 옮겨 적기, ① 오늘의 질문(근거 지표 빈칸), ② 행사 정하기(묶음 상품 · 교차 할인 빈칸, 처음 행사 맞다/아니다) + 저장 |

- 표의 첫 줄(회색)은 예시로 미리 적어 둔 줄입니다.
- 3~5단계에서는 [표1]을 접기 상자로 다시 볼 수 있습니다.

## 저장

- 오른쪽 위 **저장하기**(또는 Ctrl + S)를 누르면 답이 **이 브라우저(localStorage)** 에 저장됩니다. 서버로는 아무것도 보내지 않습니다.
- 같은 컴퓨터·같은 브라우저로 다시 열면 저장한 답이 그대로 나옵니다. 저장하지 않고 탭을 닫으려 하면 한 번 묻습니다. 마지막 단계의 **저장한 답 지우기**로 지울 수 있습니다.
